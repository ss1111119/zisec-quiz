## 現在在做的事：選項間距改版

考後使用者回報考場的真實題型，據以重寫自製題庫的**選項**。要解決的問題是
**「我出的選項太好刪」**——真考場四個選項彼此極近，難度在選項間距，
而自製題庫常有一眼就能排除的玩笑選項。

### 已定案的做法（使用者選的，別再問）

- **覆蓋原檔**，不另存 `-r` 新檔（原版留在 git 歷史；另存會讓題庫數翻倍，
  且全庫模擬考會抽到同考點的兩套題、答案還不同）。v15r 是例外，它是最早的示範檔。
- **不寫逐題註解**，只在檔尾寫統一的改版說明。
- **官方自我評量 90 題（`official-001-090.md`）不動**——那是考場逐字原文，是比對基準。
- **一批一個檔、一個 commit，每批做完回報，等使用者點頭再往下**。

### 改版的三件事

1. **移除複選題的「（應選 N 項）」數量提示**——考場不告知應選幾項。
2. **收緊選項間距**：把玩笑選項（實彈射擊、高級烹飪、股東資產證明之類）
   換成「真實存在但歸屬錯誤」的干擾項。常見的錯置有三類：
   文件錯置、範疇錯置、階段／對象錯置。
3. **改寫為情境權衡型，每份至少四成**：給定帶限制條件的情境，
   四個選項所述做法**均為教材或法規所載之真實做法、無一為假**，
   差別僅在是否切合該限制條件。解析末以粗體寫出可遷移的判準，
   有時另註明「若情境改為某某，答案即轉為某選項」。

## 接手時請做

1. **每一題都回查教材或法規 PDF 原文再斷言**，不要憑印象。
   這個專案裡發生過好幾次未查證就下結論被抓包。做不到查證就不要寫進解析，

4. 每修一個配對，若該配對在 cheatsheet 第〇節或第廿九節未收錄，
   補一則「鑰匙」式判準，不是純表格。
5. commit message 用中文寫清楚「查證了什麼、改了什麼、為什麼」。
6. 若使用者委派 agy 執行查證或整理，**agy 的結論一律自行複驗**，

## 解析器（parseQuiz）的坑

`index.html` 只讀 `banks/index.json`，**新題庫沒登記就完全看不到**。此外：

- 解析器用 `第\s*(\d+)\s*題` 切題，**內文（含檔頭檔尾）出現「第 18 題」就會生出幽靈題**。
  但檔尾註記區有**兩個**都有效的截斷標記——`index.html` 第 222 行是
  `text.split(/出題後檢查表|【本次出題統計】/)[0]`，**「出題後檢查表」也會截斷**。
  v2～v10 與 official 用的是「出題後檢查表」，v11 之後用「【本次出題統計】」，兩者都對。
  （「第 12、29、39 題」這種寫法不會誤觸，因為數字後面不是緊接「題」。）
  **寫驗證腳本時兩個標記都要實作**——我只實作一個，就誤判 v2 有 26 個幽靈題、
  還差點動手「修」了 10 個檔（包含不該動的 official）。要查解析器行為就去讀
  `index.html` 原始碼，不要憑記憶重現。
- 解析器會把「教材依據：」之後的所有文字都當成出處，註解要放在解析之後、教材依據之前。
- Bash 工具的 heredoc 太長會被截斷，長腳本要先寫成 `.py` 檔再執行。
- **PowerShell 的 here-string（`@'...'@`）在 Bash 工具裡不能用**，
  會讓 commit message 多出一行 `@`（v11 那次就中了，已 amend 修掉）。

## 每批做完必跑的驗證

用 Python 重現 parseQuiz 邏輯實測，至少檢查：
解析出的題數與無幽靈題、題號連續、單複選題數相符、答案是否都在選項內、
解析引用的代號是否都存在、教材依據是否為空、是否殘留「應選」字樣。

**另外務必查正解分布**：改寫時很容易讓答案集中在某個字母。
v11 改版前單選 33 題有 14 題答案是 (A)，且第 21～26 題連續五題同為 (A)；
v12 改版前更誇張，46 題單選有 20 題是 (A)。
目標是四個字母大致平均、最長連續同答案不超過 3 題；複選題的答案組合也要打散，
不要全部都是 `A,B,C`。

**複選題要特別檢查「四個選項是不是全對」**：v12 第 7、11 題原本四個選項全部正確、
答案就是 A,B,C,D，等於送分。舊批次凡是「應選 4 項」而選項恰好四個的，幾乎都是這種。
處理方式是增列第五個選項（解析器支援到 G），放一個真實存在但歸屬錯誤的干擾項。

**另一種好用的干擾**：拿**題幹已經排除掉的正確敘述**當選項。
例如題幹寫「除符合法規要求外，尚有哪些意涵」，就把「法規遵循」放進選項——
它本身完全正確，只是被題幹排除了，能測出有沒有讀到那個排除語（v12 第 39 題）。

## v3 這批新學到的

- **改版時要順便查「這個考點在來源裡到底有沒有」**。v3 第 36 題考「職能訓練證書
  效期由 3 年展延為 5 年、115 年 4 月起適用」，其教材依據標的是
  「資安職能訓練取證與維持有效性規範」——該文件根本不在專案的來源清單裡。
  把三份教材 PDF 與全部法規 PDF 轉文字後逐字檢索，查無任何效期年數、展延或
  換證評量的記載。已改命為同節可查證的考點（4.8.1 證照證書配置人數）。
  **舊批次凡教材依據不是「第 N 單元」或法規條次者，都要當成待查。**
- **「極高」這種虛構等級是選項自曝的典型**。資通系統防護需求等級只有高／中／普，
  舊題把「極高」放進選項，考生一望即知可刪，等於白送一格。改法是不要用等級名稱
  當四個選項，改成「等級＋判斷理由」的 2×2，四個讀法都貼著附表十的結構。
- **干擾項最好的來源是「同一部法規的另一條」**。v3 第 50 題（應變作業規範）拿
  第 4 條的通報作業規範項目當干擾，第 23 題拿施行細則 §7II 的委外查核項目干擾
  人員作業辦法 §4 的查核項目——選項單獨讀全部為真，只是屬於另一份文件。
  這比自己編造敘述可靠得多，也不需要另外查證。
- **查完的原文留著**。把全部 PDF 用 PyMuPDF 轉成 .txt 放暫存目錄再 grep，
  比每次重新開 PDF 快很多，解析裡的引文也能直接字串比對驗證。
  （`python -c "import fitz"` 可用，pdfplumber／PyPDF2 沒裝。）
- **複選題增列第五個選項後，正解組合才有打散的空間**。四選三只有四種組合，
  五選三有十種，v3 十題複選剛好做到組合互不重複。

## v4 這批新學到的

  「A 級及 B 級每年辦理一次」，核對教材 7.5.2 表 48 與附表一／三／五原文為

  **不要因為檔尾寫著「已完成法規原文正確性掃查」就跳過查證**——v4 檔尾正是
  這樣寫的，而這一題仍然是錯的。
- **檔尾自己列的「事實待確認」要當成待辦清單逐項結清**。v4 列了三項，
  查下來一項有誤（會報任務）、兩項無誤（VANS 頻率、資安長條次），
  結清後要寫明結論，不要讓它一直掛著。
- **同一個虛構考點會跨檔重複出現**。v4 第 33 題的「CNS 27005 用語對照表」
  （風險修改→風險減輕之類）教材查無，而 v9 檔尾早就記過同一件事。
  改版時若發現某考點查無，**順手 grep 其他題庫**，很可能不只一處。
- **選項內不要留編輯註記**。v4 第 18 題的解析裡夾著「（註：本題原選項 (D)……
  已改寫。）」，那段會被測驗器當成解析顯示給考生。註記一律放檔尾。
- **五個選項正好有十種三選組合**，一份題庫十題複選剛好可以做到組合全不重複，
  v4 做到了。改完用 check_bank.py 看「複選組合」那行即可確認。
