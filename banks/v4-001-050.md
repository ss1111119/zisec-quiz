第 1 題

【單元：第 1 單元】
【題型：單選】
【核心考點：主要資產與支援資產之定義與分類判斷】

題目：
依據我國國家標準 CNS 27002：2023 對於資產分類之定義，下列何者屬於「主要資產（Primary Assets）」？

(A) 人員
(B) 營運過程與活動
(C) 應用軟體
(D) 場域（如機房、辦公地點）

答案：B

解析：
CNS 27002：2023 將資產細分為主要資產（包含資訊、營運過程與活動）及支援資產（包含硬體、軟體、網路、人員、場域及組織結構）。人員、軟體、場域皆為支持主要資產運作所需的基礎設施與資源，屬於支援資產。

第 2 題

【單元：第 1 單元】
【題型：單選】
【核心考點：資通系統與資通服務之用詞定義與實例區分】

題目：
依據《資通安全管理法》第 3 條之用詞定義，關於「資通系統」與「資通服務」的差異及實例，下列敘述何者正確？

(A) 差勤系統與公文系統屬於資通服務，個人電腦維護服務屬於資通系統
(B) 資通系統是運作的主體，資通服務則是圍繞在資通系統周邊並確保其持續可用之支援性活動
(C) 資通服務不涉及資訊的蒐集、控制、傳輸或儲存
(D) 伺服器硬體本身屬於資通服務，維護合約屬於資通系統

答案：B

解析：
資通系統是指用以蒐集、控制、傳輸、儲存、流通、刪除資訊或對資訊為其他處理、使用或分享之系統（運作的主體，如公文系統、差勤系統）；資通服務是指與資訊之蒐集、控制、傳輸、儲存、流通、刪除、其他處理、使用或分享相關之服務（確保主體可用之支援性活動，如個人電腦維護服務、伺服器維護服務）。

【核心考點：法律遵循性安全需求構面之衝擊嚴重性判定】

題目：
某機關之公開資訊網站僅提供一般民眾查詢宣導性質文件，其網頁內容不含機敏或個人資料。若對此網站進行防護需求分級評估，在僅屬一般法規規範情形之下，其「法律遵循性」之安全等級應判定為下列何者？

(B) 中級
(C) 高級

在資通安全風險管理流程中，關於各個步驟之關聯與執行方式，下列敘述何者正確？

(A) 風險溝通及諮詢是流程中獨立的單一階段，僅在風險接受後執行
(B) 風險評鑑結果若不允當，應直接進入風險處理階段

(A) 二者是互相排斥且只能二選一的作法
(B) 初期先採高階風險評鑑快速建立風險概觀，隨後針對高風險資產或發生資安事件之系統執行詳細風險評鑑

【題型：複選】
【核心考點：數位簽章之安全特性與流程原理】

題目：
在網路傳輸中，使用數位簽章（Digital Signature）技術可以同時提供下列哪些安全特性？（應選三項）

(A) 機密性（Confidentiality）
(B) 完整性（Integrity）
(C) 鑑別性（Authenticity）
(D) 不可否認性（Non-repudiation）

答案：B, C, D

解析：
數位簽章由發送方將明文透過雜湊函式產出訊息摘要，再利用發送方的私密金鑰對摘要加密；接收方以發送方的公開金鑰解密並比對摘要。此機制可驗證資料未被修改（完整性）、確認發送者確實為私鑰持有者（鑑別性），且因私鑰僅發送方擁有而無法抵賴（不可否認性）。但數位簽章並未將明文加密，故不提供機密性。

(A) 應用軟體資產（最上層） ── Adobe 系列軟體、MySQL 資料庫、MS Office 等
(B) 應用框架與程式語言（中間層） ── Java Struts2、PHP、.NET 等
(C) 應用程式中介軟體（支撐層） ── Windows Server 及其他 Windows 系列作業系統
(D) 作業系統（最底層） ── 支撐所有應用程式及服務運行的最底層基礎平台

答案：C

解析：

第 44 題

【單元：第 7 單元】
【題型：單選】
【核心考點：非侵入式與侵入式檢測之特性與生產環境適用】

題目：
在執行資通系統之安全性檢測時，通常會區分非侵入式檢查與侵入式測試。關於這兩者的特性與應用情境判定，下列敘述何者正確？

(A) 弱點掃描一律採用侵入式檢查，因為必須對系統進行實際攻擊，才能找出潛在漏洞
(B) 非侵入式檢查發送特定請求後分析回應以推斷弱點，不修改系統配置、資料或運行狀態，在線上運行且穩定性要求高的「生產環境」中是首選的測試方式
(C) 侵入式測試因為對系統完全無負面影響，故在線上生產環境中可以隨時執行，且執行前不需要取得系統所有者授權
(D) 只有滲透測試才使用非侵入式檢查，弱點掃描則專屬高侵入性

答案：B

解析：
弱點掃描主要採用非侵入式檢查。非侵入式不會對目標系統之配置、資料或運行狀態造成負面影響，是線上運行生產環境首選的測試方式。侵入式測試存在導致系統不穩定或資料損壞的風險，通常在測試環境執行，且執行前必須取得目標系統所有者明確授權。

第 7 單元，侵入式與非侵入式檢測

第 45 題

【單元：第 7 單元】
【題型：單選】
【核心考點：弱點修補原則與防禦對策決策】

題目：
某機關對其核心 Web 應用系統進行弱點掃描與檢測後，報告列出數個與程式開發相關的安全漏洞。關於機關應採取的弱點修補策略，下列哪一項敘述符合最佳實務？

(A) 不論機關或開發商是否有能力修改程式原始碼，一律只能裝設 Web 應用程式防火牆來修補弱點，不得改動原始碼
(B) 若機關或開發商有能力修改程式，應優先修補發現之程式碼弱點，從根本上解決問題；若無能力修改程式，則建議建置 Web 應用程式防火牆進行弱點防禦，作為外層防護
(C) 只要建置了 WAF，即可視為該漏洞已完全消除，不需再透過後續複掃來確認弱點排除狀態
(D) 弱點掃描僅需將初次測試報告存檔備查即可，法規並無強制要求修補後進行複掃驗證

答案：B

解析：
有能力修改程式者應優先修補應用程式原始碼；無能力修改程式者建議建置 Web 應用程式防火牆作為外層防禦。不論採取何種修補方式，檢測流程均要求必須執行複掃，以確認弱點確實修補或已被有效阻擋。

依據《資通安全責任等級分級辦法》之技術面應辦事項規定，關於各級機關針對全部「核心資通系統」辦理弱點掃描及滲透測試之法定頻率要求，下列敘述哪些正確？（應選二項）

第 47 題

【單元：第 8 單元】
【題型：單選】
【核心考點：委外廠商遠端維運「原則禁止、例外允許」之控制原則】

題目：
近年來多起資安事件顯示，駭客常利用委外廠商遠端維運的機制漏洞間接入侵機關系統。機關若確有需要開放委外廠商遠端存取時，依據「原則禁止、例外允許」之防護原則，下列哪一項安全控制措施正確？

(A) 遠端存取權限原則上應採取長天期（如一年期）固定開放，以提升廠商緊急維護時之便利性
(B) 開放遠端存取期間原則上以「短天期（臨時性）」為限，用完即關閉，且於維護結束後應確實關閉網路連線，並更換遠端存取通道之登入密碼
(C) 為精簡操作步驟，廠商於完成維護作業後，可保持 VPN 通道持續連通，密碼亦無須更換
(D) 機關應給予廠商最高信任，不需透過 SOC 或資安監控機制對廠商之遠端存取連線進行異常行為稽核

答案：B

解析：
遠端存取權限應臨時性開放，原則以短天期為限，避免長期開啟成為安全漏洞，結束後應即時確實關閉網路連線並更換登入密碼。機關必須對所有遠端存取連線實施異常行為管理機制，監控非工作時間登入、異常 IP、大量資料傳輸等。

【核心考點：資安演練項目之法定辦理頻率】
