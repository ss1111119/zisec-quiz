# 資通安全概論 模擬測驗

自用的資通安全概論練習工具。把 NotebookLM／Gemini 產出的題目貼進去，
答案與解析會先藏起來，交卷後才揭曉。

## 線上使用

開啟 GitHub Pages 網址即可，手機也能用。內建題庫可直接點「載入」開始作答。

## 功能

- 作答時只顯示題幹與選項，答案、解析、教材依據全部隱藏
- 倒數計時（依題數換算，50 題＝75 分鐘，與正式考試相同）
- 題號面板顯示**已選答案代號**，未作答者標紅框，可點擊跳題
- **★ 註記待回頭**：第一輪先做有把握的、不確定的標星跳過，第二輪回頭處理
- 每題可**取消作答**；交卷前若仍有未作答或未處理的★會跳提示
- 交卷後計分，換算成正式考試口徑（50 題滿分 100、70 分及格）
- 逐題檢討：正解、你的選擇、解析、教材依據
- 只看錯題／只重做錯題（本次作答）
- **錯題本**：交卷後自動記錄答錯的題目，存在 localStorage，跨次作答與重新整理都不會消失；
  下次答對同一題就自動移除，清單即「還沒攻克的題目」。以題幹雜湊辨識題目，換題庫檔案也認得出同一題
- 列印試題卷（不含答案）
- 累積題庫與錯題本存在瀏覽器 localStorage，可匯出「已考過考點」清單；備份 JSON 同時包含兩者
- 累積題庫**自動去重**：同一份題庫重複作答不會重複累積；既有重複資料可用「清理重複題目」清除

## 目錄

| 路徑 | 用途 |
|---|---|
| `index.html` | 測驗器本體，單一檔案、無外部相依 |
| `banks/index.json` | 內建題庫清單 |
| `banks/official-001-090.md` | **官方自我評量 90 題**（數位發展部資通安全署 115.8），非 LLM 生成 |
| `banks/v*.md` | LLM 依教材與法規產出之模擬題庫（v2～v10，450 題）|
| `docs/命題規則_輕量版.md` | 日常出題用：重多元性與正確性，不做去重 |
| `docs/命題規則_精簡版.md` | 嚴格去重版命題規則（需搭配已考過考點清單當 source）|
| `docs/命題規則_v2.md` | 完整版命題規則，含每條規則的由來 |
| `docs/已考過考點清單.md` | 上傳 NotebookLM 當 source 的考點黑名單，含知識點群 A～Z |
| `docs/去重報告.txt` | 全庫交叉去重結果，依條項款與具體事實分群 |
| `tools/dedupe_all.py` | 全庫交叉去重工具（跑法見報告開頭）|
| `cheatsheet.html` | 速查表，23 節，全部比對過法規原文 |

官方教材與法規 PDF 未納入版控（見 `.gitignore`）。

## 出題流程

1. 聊天框貼 `docs/命題規則_輕量版.md`，加一句「出 25 題」
2. 收到題目後貼進測驗器作答

需要嚴格避免重複時，改貼 `docs/命題規則_精簡版.md`，
並把 `docs/已考過考點清單.md` 上傳成 NotebookLM 的 source。
實測顯示模型不會誠實比對黑名單，因此重複與否仍建議事後檢查：

- `tools/dedupe.py`：新一批 vs 已考過考點清單，單向比對，靠文字相似度。
- `tools/dedupe_all.py`：全庫交叉比對，靠條項款與具體事實等結構化訊號，
  結果見 `docs/去重報告.txt`。

## 題庫品質提醒

題目由 LLM 依官方教材與法規產出，**v2 至 v10 共 450 題已全數比對法規原文**，
修正內容記在各題庫檔案末尾的「出題後檢查表」段落（含修正項目、核對通過清單與待確認事項）。

已知的系統性問題：

- 模型會產出格式正確但查無此文的「假引文」，這類錯誤可直接用引文字串 grep 法規全文查出。
- 條號、款次與憑空補上的數字是最常見的錯誤來源；教材本身亦有數處停留在 115.1.7 修正前。
- 450 題中有 57% 命中重複訊號，高頻考點集中在委外八款與幾組法定數字，詳見 `docs/去重報告.txt`。

拿來練習沒問題，但遇到與速查表不一致時，以速查表為準（速查表逐節比對過法規原文）。
