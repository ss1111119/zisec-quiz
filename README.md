# 資通安全概論 模擬測驗

自用的資通安全概論練習工具。把 NotebookLM／Gemini 產出的題目貼進去，
答案與解析會先藏起來，交卷後才揭曉。

## 線上使用

開啟 GitHub Pages 網址即可，手機也能用。內建題庫可直接點「載入」開始作答。

## 功能

- 作答時只顯示題幹與選項，答案、解析、教材依據全部隱藏
- 倒數計時（依題數換算，50 題＝75 分鐘）
- 交卷後計分，換算成正式考試口徑（50 題滿分 100、70 分及格）
- 逐題檢討：正解、你的選擇、解析、教材依據
- 只看錯題／只重做錯題
- 列印試題卷（不含答案）
- 累積題庫存在瀏覽器 localStorage，可匯出「已考過考點」清單

## 目錄

| 路徑 | 用途 |
|---|---|
| `index.html` | 測驗器本體，單一檔案、無外部相依 |
| `banks/index.json` | 內建題庫清單 |
| `banks/*.md` | 題庫內容 |
| `docs/命題規則_精簡版.md` | 每次貼進 NotebookLM 聊天框的命題規則 |
| `docs/命題規則_v2.md` | 完整版命題規則，含每條規則的由來 |
| `docs/已考過考點清單.md` | 上傳 NotebookLM 當 source 的考點黑名單，含知識點群 A～Z |

官方教材與法規 PDF 未納入版控（見 `.gitignore`）。

## 出題流程

1. 把 `docs/已考過考點清單.md` 上傳成 NotebookLM 的 source
2. 聊天框貼 `docs/命題規則_精簡版.md`，加一句「出 25 題」
3. 收到題目後貼進測驗器作答
4. 把新增考點追加回 `docs/已考過考點清單.md`，重新上傳覆蓋

## 題庫品質提醒

題目由 LLM 依官方教材與法規產出，**未逐題經人工核對法條原文**。
已知的重複題與來源存疑題記在各題庫檔案末尾的「出題後檢查表」段落。
拿來練習可以，不要當成正確答案的權威來源。
